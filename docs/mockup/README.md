# Mockup

Clickable HTML screens, one set per role, with made-up demo data that matches the seeded demo data. They open straight from the folder, no server needed.

**Start here:** [index.html](index.html), then pick a role.

| Role | Screens |
|---|---|
| Consultant | [Book time](consultant-book.html) (with a rejected booking message), [My bookings](consultant-bookings.html) |
| Project lead | [Orders and budget](project-lead-orders.html): gauge, forecast, traffic light |
| Purchasing | [Follow-up orders](purchasing-follow-ups.html), most urgent first |
| Finance | [Proof of work](finance-proof.html): monthly hours per person, approve or reject |

The running app (see the main README) shows the same screens with live data. The mockup is the design reference we built them from, and it is the fallback if the app does not start.
